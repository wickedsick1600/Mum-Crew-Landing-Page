# The Mum Crew — Palm Trees CrewCup landing page

A focused, customer-facing paid-traffic landing page built with HTML, CSS and JavaScript.

## Included

- Responsive static landing page for GitHub Pages
- Conversion-focused product benefits, offer and FAQ sections
- Sticky mobile purchase CTA
- Supplied product imagery with responsive, aspect-ratio-safe styling

## Preview locally

Open `index.html` directly, or run any small static server from this folder.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will display the live URL after deployment.

The page includes `noindex, nofollow` metadata. Remove that tag if the page is approved for a live, indexable campaign.

## Notes

- The CTA links to the live Palm Trees product page.
- Pricing and review counts are time-sensitive and should be checked before publication.
- The static page intentionally does not simulate cart behavior.
